# Triage labels

| Rôle canonique | Label GitHub | Signification |
| --- | --- | --- |
| needs-triage | needs-triage | À évaluer |
| needs-info | needs-info | Informations attendues |
| ready-for-agent | ready-for-agent | Prêt pour un agent autonome |
| ready-for-human | ready-for-human | Intervention humaine requise |
| wontfix | wontfix | Ne sera pas traité |

Les compétences doivent utiliser cette correspondance lorsqu'elles
mentionnent un rôle de triage.
