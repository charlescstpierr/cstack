### Autopilot-full

Follow [the Codex runtime contract](../references/codex-runtime.md).

**You own the verdicts. One owner runs each independent PR from build through merge, and no PR merges without an independent verdict.** Use this playbook when the user authorizes a queue of PRs and grants merge authority in the current conversation. Use `autopilot-stack.md` when the user keeps landing authority.

1. **Record scope and authority.** Mark items the operator reserves for personal review or merge. If the request asks only for a protocol or plan, return that artifact and stop. Record the exact sentence in which the user granted merge authority. Without that sentence, run `autopilot-stack.md` instead. The recorded grant plus a clean non-author verdict is the merge authorization. This playbook never authorizes itself. Record the objective, queue, done predicate, and that sentence in `.cstack/`.
2. **Assign one owner per PR.** Use git and `gh` only. Each bounded owner gets exclusive files and a branch. Its lifecycle includes implementation, `../../deslop/SKILL.md` over the diff before each commit, an early pushed snapshot, an authorized ready PR, proof on the real artifact, automated-review triage from `../references/bugbot-triage.md`, `../../no-comments/SKILL.md` before review, prose cleanup through `../../technical-writing/SKILL.md` and `../../unslop/SKILL.md`, a rebase onto current trunk, `babysit.md`, and merge after step 4. Keep `deslop skipped: <reason>` when a step genuinely cannot run it. Each owner writes a `decisions.tsv` trail under `.cstack/`. Do not create or publish a PR unless the user's request grants that authority.
3. **Run independent owners concurrently.** Bound concurrency to native capacity. Run extra owners in waves. Keep one writer per branch and disjoint files. Serialize overlapping work. Independent PRs branch from trunk. Dependent work starts after its parent merges. Models inherit unless `.cstack/models.json` supplies an available override for the owner's matched work.
4. **Verify every merge-ready head independently.** At the owner's reported head SHA, run independent verification lanes for the distinct risks. Include repository gates, a live check of the load-bearing behavior, a comparison with trunk, and a diff-and-receipts audit that distrusts the PR body. Bound how many lanes run at once to native capacity and run extras in waves. A missing slot serializes a lane. It never drops one. The verdict comes from an actor that did not write the code. When no subagent is available, run a separate review pass over a clean re-read of the diff, label it `single-agent review`, and name the missing independence. Aggregate one verdict. Send findings back to the owner. A changed head requires a fresh verdict unless the patch-ID rule in `shipping.md` preserves the code verdict.
5. **Merge only after the clean verdict.** Rebase onto current trunk before the merge-ready report. Pin the verdict to the head SHA and patch ID. Merge only when the recorded grant from step 1 is present and the non-author verdict is clean. The owner may then squash-merge its PR with `gh`. Operator-reserved items stop at merge-ready. After confirmed merge and verification, the owner returns its worktree, head, evidence and release status. The coordinator runs the **After a completed delivery** mode in [worktree cleanup](worktree-cleanup.md) for completed, released units; keep worktrees needed by the next item or a verifier.
6. **Audit at every drain.** Before refilling owners, and at every verification boundary, re-read this playbook and the execution playbooks from the installed plugin bundle on disk, not from memory. Audit the operation against them. Fix drift in that pass. Then post a status message to the operator in chat whether or not anything changed. Continue in the foreground while the session remains active. Count commits, pushes, PR deltas, checks, and recorded verdicts as progress. Replace a stalled owner only after inspecting its state. Use a native scheduler only when the session exposes one and the user asked for it. Nothing is promised after the app closes.
7. **Honor stop immediately.** On the operator's stop or hold, interrupt owners and issue a zero-writes instruction. Preserve current state under `.cstack/`.

**Reply:** Report the queue with owner, state, and head SHA; each independent verdict; merged PRs; next items; reserved operator gates; and the `.cstack/` trail paths. Quote the recorded merge-authority sentence. Every claim carries its evidence or its label in the same sentence. Measured, inferred, or guess. A prediction or an unseen cause is a guess. Never hand the human a check you could run.
