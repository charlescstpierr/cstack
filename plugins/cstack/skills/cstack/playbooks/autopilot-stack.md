### Autopilot-stack

Follow [the Codex runtime contract](../references/codex-runtime.md).

**You own the stack and its verification. The operator owns landing.** Build the queue as one linear base-branch chain and stop at a verified handoff.

1. **Run one owner per change.** Use git and `gh`. Each bounded owner builds its change, runs `../../deslop/SKILL.md` over the diff before each commit, pushes an early snapshot, opens an authorized ready PR before final proof, proves the real behavior, triages automated review through `../references/bugbot-triage.md`, applies `../../no-comments/SKILL.md` before review, applies `../../technical-writing/SKILL.md` and `../../unslop/SKILL.md`, and drives the PR green with `babysit.md`. Keep `deslop skipped: <reason>` when a step genuinely cannot run it. Keep its `decisions.tsv` trail under `.cstack/`. Do not create or publish PRs unless the request grants that authority.
2. **Audit at every drain.** Before refilling owners, and at every verification boundary, re-read this playbook and the execution playbooks from the installed plugin bundle on disk, not from memory. Audit the operation against them. Fix drift in that pass. Then post a status message to the operator in chat whether or not anything changed. Count only observable side effects as progress. Replace a stalled owner only after inspecting its state. Use a native scheduler only when the session exposes one and the user asked for it. Nothing is promised after the app closes.
3. **Hold operator gates.** If the request asks only for a protocol or plan, return it and stop. Execution starts only on the operator's explicit go in the current conversation. A playbook never authorizes itself. On an explicit stop, interrupt every owner and preserve `.cstack/` state.
4. **Verify each stack-ready head.** Pin the owner's report to the exact SHA. Run repository gates, live behavior checks, a trunk comparison, and a receipts-and-diff audit. Bound how many lanes run at once to native capacity and run extras in waves. A missing slot serializes a lane. It never drops one. The verdict comes from an actor that did not write the code. When no subagent is available, run a separate review pass over a clean re-read of the diff, label it `single-agent review`, and name the missing independence. Findings return to the owner. Nothing enters the delivered stack without a clean verdict.
5. **Append; do not ship.** Owners never merge, arm auto-merge, or close PRs. A clean verdict permits the topology owner to append that PR to the linear stack in verified or operator-specified order.
6. **Use one topology writer.** Owners push only their branches and report the tip, base, and intended parent. The root is the only topology writer. Before a rebase or force-with-lease push, verify the remote branch tip with `git ls-remote`. Rebase the child onto the exact parent tip, push with `--force-with-lease`, and set its base with `gh pr edit <pr> --base <parent-branch>`. Never `--force`. Only the root PR targets trunk.
7. **Absorb trunk drift from bottom to top.** Fetch current trunk and rebase the chain in order. The owner fixes conflicts in its files. Every rewrite changes descendant SHAs. Compare each PR's stable base-to-head `git patch-id` with the patch ID recorded at verdict time. Preserve the code verdict only when the patch ID is unchanged, then re-run mergeability and CI. Re-verify every changed patch.
8. **Deliver the chain.** Return one linear chain of verified PRs, reviewable bottom-up on GitHub. Keep verdicts in `.cstack/` unless the user authorized posting them. The operator reviews and lands the chain.

Use Autopilot-full for independent PRs with explicit landing authority. Use Autopilot-stack for coupled work, sequenced work, or retained landing authority.

**Reply:** Link the stack root and tip, give one verdict line per PR, and name excluded or parked work with its reason. Every claim carries its evidence or its label in the same sentence. Measured, inferred, or guess. A prediction or an unseen cause is a guess. Never hand the human a check you could run.
